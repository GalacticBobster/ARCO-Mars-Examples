# ARCO-Mars-Examples
Examples for accessing ARCO-Mars surface and atmosphere reanalysis data


##Note
There are two example directories. One for [Hugging Face](https://huggingface.co/) platform, and the other one for [EarthMover](https://www.earthmover.io/). 

## Examples
The Examples directly contains python files to access and manipulate the ARCO-Mars data on your own system.

- surface_column_variables.py: Comparing the surface variables between ARCO-EMARS, ARCO-MACDA and ARCO-OpenMARS
- wind_comparison.py: Extracting the changes between temperature, zonal and meridional wind speeds from the three ARCO-Mars products
- dust_mmr.py: Latitude averaged temperature profiles during MY 28 Global Dust Storm. ARCO-MACDA dust mixing ratio, and optical depth map
